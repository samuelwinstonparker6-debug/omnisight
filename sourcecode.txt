# OmniSight

**Multimodal UI Self-Healing & RPA Agent**

OmniSight is an intelligent agent designed to automatically scan web applications, detect visual and layout bugs using Vision-Language Models (VLMs), generate code fixes, and submit Pull Requests directly to your repository.

## Architecture

![Architecture](docs/architecture.md)

1. **Browser Automation**: Uses Playwright to navigate to target URLs and capture full-page screenshots across multiple viewports (desktop, tablet, mobile).
2. **VLM Analysis**: Sends screenshots to a Vision-Language Model (like Gemini) to detect layout bugs, contrast issues, overlapping elements, and accessibility violations.
3. **Agent Orchestrator**: Uses a LangChain-based ReAct agent to orchestrate the pipeline and generate CSS/HTML fixes based on the VLM's analysis.
4. **GitHub PR Creator**: Commits the generated fixes to a new branch and automatically opens a Pull Request on the target repository.

## Project Structure

- `backend/`: FastAPI server for triggering scans and viewing results.
  - `services/browser/`: Playwright automation.
  - `services/vlm/`: Gemini Vision integration.
  - `services/agent/`: LangChain orchestration.
  - `services/github/`: PyGithub PR integration.
- `mock-app/`: A sample e-commerce application with deliberate UI bugs for testing the agent.
- `frontend/`: React dashboard (coming soon).
- `tests/`: Unit and integration test suite.

## Setup Instructions

1. Clone the repository.
2. Ensure you have Python 3.10+ installed.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Copy the environment variables template and configure your keys:
   ```bash
   cp .env.example .env
   ```
   Add your `GEMINI_API_KEY` and `GITHUB_TOKEN` to the `.env` file.
5. Start the development server:
   ```bash
   python scripts/start_dev.py
   ```

@router.post("/scan", summary="Trigger UI scan")
async def trigger_scan(
    url: str | None = None,
    db: AsyncSession = Depends(get_db_session)
) -> dict[str, Any]:
    """
    Trigger a full UI scan on the target URL.

    This endpoint will:
    1. Launch a headless browser via Playwright
    2. Capture screenshots at multiple viewports
    3. (Day 3) Send screenshots to the VLM for analysis
    4. Return identified UI bugs

    Args:
        url: Target URL to scan. Falls back to STAGING_URL from config.
        db: Database session.

    Returns:
        Scan result with identified issues or captured screenshots (Day 2).
    """
    settings = get_settings()
    target_url = url or settings.staging_url
    
    # Initialize run record
    run_id = str(uuid.uuid4())
    started_at = datetime.now(timezone.utc)
    run_model = ScanRunModel(
        id=run_id,
        url=target_url,
        status=ScanStatus.RUNNING,
        started_at=started_at,
    )
    db.add(run_model)
    await db.commit()
    
    # 1. Capture screenshots (Day 2)
    screenshots = await capture_screenshots(
        url=target_url,
        headless=settings.browser_headless
    )
    
    if not screenshots:
        raise HTTPException(status_code=502, detail="No screenshot captured from the target URL.")
    
    # 2. VLM Analysis (Day 3)
    all_bugs = []
    db_bugs = []
    
    for viewport, image_path in screenshots.items():
        analysis = await analyze_screenshot(
            image_path=image_path,
            page_url=target_url,
            viewport=viewport
        )
        if analysis.get("status") == "success":
            for bug_data in analysis.get("bugs", []):
                # Ensure the bug object has required fields like category and severity
                bug_data["viewport"] = viewport
                bug_data["screenshot_path"] = image_path
                all_bugs.append(bug_data)
                
                bug_id = str(uuid.uuid4())
                bug_model = BugModel(
                    id=bug_id,
                    scan_run_id=run_id,
                    category=bug_data.get("category", "other"),
                    severity=bug_data.get("severity", "medium"),
                    title=bug_data.get("title", "Unknown bug"),
                    description=bug_data.get("description", ""),
                    element_selector=bug_data.get("element_selector"),
                    viewport=viewport,
                    screenshot_path=image_path,
                    suggested_fix=bug_data.get("suggested_fix"),
                    confidence=bug_data.get("confidence", 0.9),
                )
                db.add(bug_model)
                db_bugs.append(bug_model)
                
    await db.commit()
    
    # 3. Verification Loop
    import os
    from backend.services.browser.automation import VIEWPORTS, capture_with_injected_css
    import logging
    
    logger = logging.getLogger(__name__)
    
    for bug_model in db_bugs:
        if bug_model.suggested_fix and bug_model.element_selector:
            try:
                # Define output path for the verification screenshot
                out_dir = os.path.join("output", "screenshots", "verification")
                os.makedirs(out_dir, exist_ok=True)
                verification_output_path = os.path.abspath(os.path.join(out_dir, f"{bug_model.id}_verified.png"))
                
                # Use in-browser injection
                fixed_img_path = await capture_with_injected_css(
                    url=target_url,
                    css_content=bug_model.suggested_fix,
                    viewport_name=bug_model.viewport,
                    output_path=verification_output_path,
                    headless=settings.browser_headless
                )
                
                if fixed_img_path and os.path.exists(fixed_img_path):
                    cropped_path = await crop_element_region(
                        image_path=fixed_img_path,
                        page_url=target_url,
                        css_selector=bug_model.element_selector,
                        viewport_name=bug_model.viewport
                    )
                    
                    verify_img_path = cropped_path if cropped_path else fixed_img_path
                    bug_model.verification_screenshot_path = verify_img_path
                    
                    verification_analysis = await analyze_screenshot(
                        image_path=verify_img_path,
                        page_url=target_url,
                        viewport=bug_model.viewport
                    )
                    
                    is_fixed = True
                    if verification_analysis.get("status") == "success":
                        for new_bug in verification_analysis.get("bugs", []):
                            if new_bug.get("element_selector") == bug_model.element_selector or new_bug.get("title") == bug_model.title:
                                is_fixed = False
                                break
                                
                    bug_model.verification_status = "verified_fixed" if is_fixed else "still_broken"
                    
                    for b in all_bugs:
                        if b.get("title") == bug_model.title and b.get("viewport") == bug_model.viewport:
                            b["verification_status"] = bug_model.verification_status
                            b["verification_screenshot_path"] = bug_model.verification_screenshot_path
            except Exception as e:
                logger.error(f"Verification loop failed for {bug_model.id}: {e}")
    
    completed_at = datetime.now(timezone.utc)
    duration = (completed_at - started_at).total_seconds()
    
    run_model.status = ScanStatus.COMPLETED
    run_model.completed_at = completed_at
    run_model.duration_seconds = duration
    run_model.total_bugs = len(all_bugs)
    
    await db.commit()
    
    return {
        "status": "success",
        "message": "Scan completed with VLM analysis.",
        "url": target_url,
        "run_id": run_id,
        "screenshots": screenshots,
        "bugs": all_bugs,
        "total_bugs": len(all_bugs)
    }

        started_at=run.started_at,
        completed_at=run.completed_at,
        duration_seconds=run.duration_seconds,
        bugs=[
            BugReport(
                id=bug.id,
                category=bug.category,
                severity=bug.severity,
                title=bug.title,
                description=bug.description,
                element_selector=bug.element_selector,

class FixRequest(BaseModel):
    action: str  # "approve" or "reject"


@router.post("/bugs/{bug_id}/action", summary="Approve or reject an AI fix")
async def action_bug_fix(
    bug_id: str,
    req: FixRequest,
    db: AsyncSession = Depends(get_db_session)
) -> dict[str, Any]:
    """Approve (create PR) or reject a suggested bug fix."""
    result = await db.execute(select(BugModel).where(BugModel.id == bug_id))
    bug = result.scalars().first()
    if not bug:
        raise HTTPException(status_code=404, detail="Bug not found")
        
    if req.action == "reject":
        return {"status": "success", "message": "Fix rejected"}
        
    if req.action == "approve":
        if not bug.suggested_fix:
            raise HTTPException(status_code=400, detail="No suggested fix available")
            
        from backend.services.github.pr_creator import create_fix_pr
        
        # We need a file path to fix. In a real system the LLM would provide this,
        # but for the mock app we can default to "mock-app/styles.css".
        file_path = "mock-app/styles.css"
        
        # --- Solve Context Loss: Read actual file and use LLM to patch it ---
        import os
        from backend.core.config import get_settings
        from langchain_google_genai import ChatGoogleGenerativeAI
        
        full_path = os.path.join(os.getcwd(), file_path)
        try:
            with open(full_path, "r", encoding="utf-8") as f:
                original_content = f.read()
        except FileNotFoundError:
            original_content = "/* Styles file not found */"
            
        settings = get_settings()
        if settings.gemini_api_key:
            llm = ChatGoogleGenerativeAI(
                model=settings.gemini_model or "gemini-1.5-pro",
                google_api_key=settings.gemini_api_key,
                temperature=0.0
            )
            prompt = (
                f"You are a frontend developer. Here is the existing CSS file:\n```css\n{original_content}\n```\n\n"
                f"The bug is: {bug.title}\nDescription: {bug.description}\nThe suggested fix is: {bug.suggested_fix}\n\n"
                "Please rewrite the COMPLETE updated CSS file incorporating this fix safely into the existing classes. "
                "Do not return any explanations, just the raw CSS."
            )
            try:
                response = await llm.ainvoke(prompt)
                fix_content = response.content
                # Strip markdown
                if fix_content.strip().startswith("```"):
                    lines = fix_content.strip().splitlines()
                    if lines[0].startswith("```"): lines = lines[1:]
                    if lines and lines[-1].startswith("```"): lines = lines[:-1]
                    fix_content = "\n".join(lines)
            except Exception as e:
                fix_content = original_content + "\n/* AI Auto-Fix */\n" + bug.suggested_fix
        else:
            fix_content = original_content + "\n/* AI Auto-Fix (Mocked) */\n" + bug.suggested_fix
        
        pr_result = await create_fix_pr(
            file_path=file_path,
            fix_content=fix_content,
            bug_description=bug.title,
            bug_severity=bug.severity,
            bug_viewport=bug.viewport,
            bug_element_selector=bug.element_selector,
            vlm_reasoning=bug.description,
            before_img_url=bug.screenshot_path,
            after_img_url=bug.verification_screenshot_path,
            original_content=original_content,
        )
        
        if pr_result["status"] == "error":
            raise HTTPException(status_code=500, detail=pr_result["message"])
            
        # Update the ScanRun's pr_url
        run_res = await db.execute(select(ScanRunModel).where(ScanRunModel.id == bug.scan_run_id))
        run = run_res.scalars().first()
        if run and not run.pr_url:
            run.pr_url = pr_result.get("pr_url")
            await db.commit()
            
        return pr_result
        
    raise HTTPException(status_code=400, detail="Invalid action")

import hmac
import hashlib
import logging
import uuid
from typing import Optional, Any
from fastapi import APIRouter, BackgroundTasks, Header, HTTPException, Request
from pydantic import BaseModel

from backend.core.config import get_settings
from backend.services.agent.orchestrator import run_pipeline

logger = logging.getLogger(__name__)
router = APIRouter(prefix="/webhook", tags=["ci-cd"])

class CICDTriggerPayload(BaseModel):
    repository: str
    branch: str
    commit_sha: str
    staging_url: Optional[str] = None
    environment: Optional[str] = "staging"

async def verify_github_signature(request: Request, signature: str, secret: str) -> None:
    body = await request.body()
    hash_object = hmac.new(secret.encode("utf-8"), msg=body, digestmod=hashlib.sha256)
    expected_signature = "sha256=" + hash_object.hexdigest()
    if not hmac.compare_digest(expected_signature, signature):
        raise HTTPException(status_code=401, detail="Invalid GitHub webhook signature")

@router.post("/ci-cd-trigger", status_code=202)
async def ci_cd_trigger(
    payload: CICDTriggerPayload,
    request: Request,
    background_tasks: BackgroundTasks,
    x_hub_signature_256: Optional[str] = Header(None)
) -> dict[str, Any]:
    """Receives CI/CD build events and triggers the OmniSight autonomous scan."""
    settings = get_settings()
    
    # Validate webhook signature if configured
    if settings.github_webhook_secret and x_hub_signature_256:
        await verify_github_signature(request, x_hub_signature_256, settings.github_webhook_secret)

    target_url = payload.staging_url or settings.staging_url
    job_id = str(uuid.uuid4())

    logger.info(f"CI/CD Webhook received for commit {payload.commit_sha}. Queuing OmniSight scan on {target_url}")

    # Dispatch the self-healing workflow in the background
    background_tasks.add_task(run_pipeline, target_url=target_url, auto_fix=True, create_pr=True)

    return {
        "status": "accepted",
        "job_id": job_id,
        "commit_sha": payload.commit_sha,
        "message": "OmniSight scan queued successfully."
    }

"""

All environment variables are loaded from .env file and validated
at startup with type checking and sensible defaults.

from functools import lru_cache
from typing import Literal

from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    """
    Application settings loaded from environment variables.

    All values can be overridden via a `.env` file in the project root
    or by setting the corresponding environment variable directly.
    """

    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=False,
        extra="ignore",
    )

    # ── Application ──────────────────────────────────────────
    app_name: str = "OmniSight"
    app_version: str = "0.1.0"
    app_host: str = "0.0.0.0"
    app_port: int = 8000
    app_debug: bool = False

    # ── Logging ──────────────────────────────────────────────
    log_level: Literal["DEBUG", "INFO", "WARNING", "ERROR", "CRITICAL"] = "INFO"

    # ── Gemini / VLM ────────────────────────────────────────
    gemini_api_key: str = ""
    gemini_model: str = "gemini-1.5-pro-latest"

    # ── GitHub ───────────────────────────────────────────────
    github_token: str = ""
    github_repo: str = ""
    github_webhook_secret: str = ""

    # ── Agent ────────────────────────────────────────────────
    max_fix_retries: int = 3

    # ── Target Application ───────────────────────────────────
    staging_url: str = "http://localhost:8000/mock-app/index.html"

    # ── Database ─────────────────────────────────────────────
    database_url: str = "sqlite+aiosqlite:///./omnisight.db"

    # ── Browser / Playwright ─────────────────────────────────
    browser_headless: bool = True
    browser_viewport_width: int = 1280
    browser_viewport_height: int = 720

    @property
    def is_gemini_configured(self) -> bool:
        """Check if Gemini API key is set."""
        return bool(self.gemini_api_key)

    @property
    def is_github_configured(self) -> bool:
        """Check if GitHub token and repo are set."""
        return bool(
            self.github_token

import logging
import sys
from typing import Optional


def setup_logging(level: str = "INFO", json_format: bool = False) -> logging.Logger:
    """
    Configure application-wide logging.

    Args:
        level: Logging level string (DEBUG, INFO, WARNING, ERROR, CRITICAL).
        json_format: If True, output logs as structured JSON (for production).

    Returns:
        Root logger configured with the specified settings.
    """
    log_level = getattr(logging, level.upper(), logging.INFO)

    # Clear existing handlers
    root_logger = logging.getLogger()
    root_logger.handlers.clear()

    if json_format:
        try:
            from pythonjsonlogger import jsonlogger

            handler = logging.StreamHandler(sys.stdout)
            formatter = jsonlogger.JsonFormatter(
                fmt="%(asctime)s %(name)s %(levelname)s %(message)s",
                datefmt="%Y-%m-%dT%H:%M:%S",
            )
            handler.setFormatter(formatter)
        except ImportError:
            handler = _create_console_handler()
    else:
        handler = _create_console_handler()

    root_logger.setLevel(log_level)
    root_logger.addHandler(handler)

    # Quiet noisy third-party loggers
    logging.getLogger("uvicorn.access").setLevel(logging.WARNING)
    logging.getLogger("httpcore").setLevel(logging.WARNING)
    logging.getLogger("httpx").setLevel(logging.WARNING)
    logging.getLogger("openai").setLevel(logging.WARNING)

    return root_logger


def _create_console_handler() -> logging.StreamHandler:
    """Create a formatted console handler."""
    handler = logging.StreamHandler(sys.stdout)
    formatter = logging.Formatter(
        fmt="%(asctime)s │ %(levelname)-8s │ %(name)-25s │ %(message)s",
        datefmt="%H:%M:%S",
    )
    handler.setFormatter(formatter)
    return handler

    FastAPI dependency that yields an async database session.

            await session.commit()

            raise
        finally:
            await session.close()

import logging

from urllib.parse import urlparse

from playwright.async_api import async_playwright

logger = logging.getLogger(__name__)

# Standard viewport configurations for responsive testing
VIEWPORTS = {
    "desktop": {"width": 1280, "height": 720},
    "tablet": {"width": 768, "height": 1024},
    "mobile": {"width": 320, "height": 568},
}

def _get_safe_filename(url: str, viewport_name: str) -> str:
    """Generate a safe filename from a URL and viewport."""
    parsed = urlparse(url)
    domain = parsed.netloc.replace(":", "_") or "localhost"
    path = parsed.path.strip("/").replace("/", "_") or "index"
    return f"{domain}_{path}_{viewport_name}.png"

async def capture_screenshots(
    url: str,
    output_dir: str = "./output/screenshots",
    viewports: Optional[dict[str, dict[str, int]]] = None,
    headless: bool = True,
) -> dict[str, str]:
    """
    Capture full-page screenshots at multiple viewport sizes.

    Args:
        url: Target URL to screenshot.
        output_dir: Directory to save screenshot files.
        viewports: Dict of viewport configs. Defaults to desktop/tablet/mobile.
        headless: Run browser in headless mode.

    Returns:
        Dict mapping viewport name to absolute screenshot file path.
    """
    logger.info("📸 Screenshot capture requested for: %s", url)
    
    # Ensure output directory exists
    out_dir = Path(output_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    
    target_viewports = viewports or VIEWPORTS
    results = {}

    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=headless)
        
        try:
            for viewport_name, dimensions in target_viewports.items():
                logger.info(f"  → Capturing {viewport_name} viewport...")
                context = await browser.new_context(
                    viewport=dimensions,
                    device_scale_factor=1,
                )
                page = await context.new_page()
                
                try:
                    await page.goto(url, wait_until="networkidle", timeout=30000)
                    
                    # Wait a bit extra for dynamic content or animations to settle
                    await asyncio.sleep(1)
                    
                    filename = _get_safe_filename(url, viewport_name)
                    filepath = out_dir / filename
                    
                    await page.screenshot(
                        path=str(filepath),
                        full_page=True,
                        type="png"
                    )
                    
                    results[viewport_name] = str(filepath.absolute())
                    logger.info(f"  ✓ Saved to {filepath}")
                    
                except Exception as e:
                    logger.error(f"Failed to capture {viewport_name}: {e}")
                finally:
                    await context.close()
                    
        finally:
            await browser.close()

    return results

async def capture_with_injected_css(

    return output_path

async def create_fix_pr(

    bug_element_selector: Optional[str] = "N/A",

    before_img_url: Optional[str] = None,
    after_img_url: Optional[str] = None,
    original_content: Optional[str] = None,
    branch_name: Optional[str] = None,
    github_token: Optional[str] = None,
    github_repo: Optional[str] = None,
) -> dict[str, Any]:
    """
    Creates a branch, commits the fix, and opens a structured PR on GitHub.
    """
    settings = get_settings()
    token = github_token or settings.github_token
    repo_name = github_repo or settings.github_repo
    
    if not token or not repo_name or token == "ghp_your-github-token-here":
        logger.warning("GitHub credentials not configured. Returning mock PR success.")
        return {"status": "success", "pr_url": "https://github.com/mock/repo/pull/999", "pr_number": 999}

    def _sync_create_pr():
        g = Github(token)
        repo = g.get_repo(repo_name)
        base_branch = repo.get_branch(repo.default_branch)
        new_branch = branch_name or f"omnisight-fix-{uuid.uuid4().hex[:8]}"
        
        # 1. Create Branch
        repo.create_git_ref(ref=f"refs/heads/{new_branch}", sha=base_branch.commit.sha)
        
        # 2. Commit Fix
        commit_msg = f"fix(ui): OmniSight auto-fix for {bug_description[:50]}"
        try:
            contents = repo.get_contents(file_path, ref=new_branch)
            repo.update_file(file_path, commit_msg, fix_content, contents.sha, branch=new_branch)
        except GithubException as e:
            if e.status == 404:
                repo.create_file(file_path, commit_msg, fix_content, branch=new_branch)
            else:
                raise
                
        # 3. Format PR Markdown Body
        before_md = f"![Before Fix]({before_img_url})" if before_img_url else "*No image provided*"
        after_md = f"![After Fix]({after_img_url})" if after_img_url else "*No image provided*"
        
        pr_body = f"""## 🤖 OmniSight Autonomous UI Self-Healing Patch

This Pull Request was autonomously generated by the **OmniSight RPA Agent** to resolve a detected visual layout regression.

### 📋 Bug Summary
| Attribute | Details |
|-----------|---------|
| **Issue** | {bug_description} |
| **Severity** | `{bug_severity.upper()}` |
| **Viewport** | `{bug_viewport}` |
| **Selector** | `{bug_element_selector}` |
| **File Modified** | `{file_path}` |

### 📸 Visual Verification
| Before (Original) | After (Verified In-Browser) |
|:---:|:---:|
| {before_md} | {after_md} |

### 🧠 VLM Diagnostic Reasoning
> {vlm_reasoning}
"""
        # 4. Create PR
        pr = repo.create_pull(
            title=f"🔧 OmniSight Fix: {bug_description[:50]}",
            body=pr_body,
            head=new_branch,
            base=repo.default_branch
        )
        return pr.html_url, pr.number, new_branch

    try:
        pr_url, pr_number, created_branch = await asyncio.to_thread(_sync_create_pr)
        return {"status": "success", "pr_url": pr_url, "pr_number": pr_number, "branch_name": created_branch}
    except Exception as e:
        logger.error(f"Failed to create GitHub PR: {e}")
        return {"status": "error", "message": str(e)}

    with path.open("rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")


def _chunk_image_base64(image_path: str, max_height: int = 1080) -> list[str]:
    """Slice a tall image vertically into multiple chunks and return their base64 strings."""
    path = Path(image_path)
    if not path.is_file():
        raise FileNotFoundError(f"Screenshot not found: {image_path}")
    
    with Image.open(path) as img:
        width, height = img.size
        # If the image is smaller than max_height, just return it as one chunk
        if height <= max_height:
            return [_load_image_base64(image_path)]
            
        chunks = []
        for top in range(0, height, max_height):
            bottom = min(top + max_height, height)
            cropped = img.crop((0, top, width, bottom))
            
            buffer = io.BytesIO()
            cropped.save(buffer, format="PNG")
            b64 = base64.b64encode(buffer.getvalue()).decode("utf-8")
            chunks.append(b64)
            
        return chunks


async def analyze_screenshot(
    image_path: str,
    page_url: str,
    viewport: str = "desktop",
    model: str = "gpt-4o",
    api_key: Optional[str] = None,
) -> dict[str, Any]:
    """
    Analyze a UI screenshot using Gemini Vision.

    Args:
        image_path: Path to the screenshot image file.
        page_url: URL of the page that was captured.
        viewport: Viewport size used for the screenshot.
        model: Gemini model identifier.
        api_key: Gemini API key (falls back to settings).

    Returns:
        Structured analysis result with detected bugs.
    """
    settings = get_settings()
    model_name = settings.gemini_model or "gemini-1.5-pro"
    key = settings.gemini_api_key
    
    # If no real API key is provided, return a mock response matching our mock app bugs
    # This allows testing the full pipeline without incurring costs
    if not key:
        logger.warning("⚠️  Gemini API key is missing. Returning MOCK analysis for demonstration.")
        
        # Simulate API delay
        import asyncio
        await asyncio.sleep(2)
        
        mock_bugs = []
        if viewport == "mobile":
            mock_bugs.append({
                "id": "bug-1-mock",
                "category": "overflow",
                "severity": "high",
                "title": "Checkout button overflows viewport",
                "description": "The checkout button has a fixed width of 400px which overflows the 320px mobile viewport.",
                "element_selector": ".checkout-button",
                "suggested_fix": "Change width: 400px to width: 100% or max-width: 100%;",
            })
        
        if viewport in ["desktop", "tablet", "mobile"]:
            mock_bugs.extend([
                {
                    "id": f"bug-2-mock-{viewport}",
                    "category": "contrast",
                    "severity": "critical",
                    "title": "Low text contrast in hero banner",
                    "description": "White text on a very light gray background (#e5e7eb) fails WCAG contrast requirements.",
                    "element_selector": ".hero-text",
                    "suggested_fix": "Change text color to a darker shade like #1f2937 or darken the background.",
                },
                {
                    "id": f"bug-3-mock-{viewport}",
                    "category": "overlap",
                    "severity": "medium",
                    "title": "Price tag overlaps product image",
                    "description": "The absolute positioning of the price container pulls it up too far (-20px) causing it to overlap awkwardly with the product image.",
                    "element_selector": ".price-container",
                    "suggested_fix": "Change top: -20px to top: 10px, or switch to relative/static positioning.",
                }
            ])
            
        for bug in mock_bugs:
            bug["screenshot_path"] = image_path
            bug["viewport"] = viewport
            bug["confidence"] = 0.95
            
        return {
            "status": "success",
            "bugs": mock_bugs,
            "viewport": viewport,
            "image_path": image_path,
            "raw_response": "MOCK_RESPONSE"
        }

    logger.info("🔍 VLM analysis requested for: %s (%s)", image_path, viewport)
    
    # Load and chunk image data
    chunk_b64s = _chunk_image_base64(image_path, max_height=1080)

    system_prompt = (
        "You are an expert UI/UX engineer. Analyze the provided screenshot chunks of a web page "
        "and return a JSON array named `bugs` describing any visual or layout issues. "
        "Each bug object must contain the following fields: "
        "`id` (string UUID or unique identifier), `category` (one of layout, contrast, overflow, overlap, responsive, "
        "accessibility, typography, interaction, other), `severity` (critical, high, medium, low, info), "
        "`title`, `description`, optional `element_selector`, `viewport`, `screenshot_path`, "
        "optional `suggested_fix`, and `confidence` (float 0.0 to 1.0). "
        "If no issues are found, return an empty array. "
        "Return strictly valid JSON without Markdown blocks or other conversational text."
    )

    llm = ChatGoogleGenerativeAI(
        model=model_name,
        google_api_key=key,
        temperature=0.0,
        max_output_tokens=2048,
    )

    content = [{"type": "text", "text": f"Analyze these screenshot chunks of {page_url} (viewport: {viewport}). The image has been sliced vertically into {len(chunk_b64s)} parts."}]
    for b64 in chunk_b64s:
        content.append({"type": "image_url", "image_url": {"url": f"data:image/png;base64,{b64}"}})

    messages = [
        SystemMessage(content=system_prompt),
        HumanMessage(content=content)
    ]

    try:
        response = await llm.ainvoke(messages)
        raw = response.content
        if isinstance(raw, list):
            raw = "".join([str(p.get("text", p)) if isinstance(p, dict) else str(p) for p in raw])
    except Exception as exc:
        logger.error("Gemini VLM request failed: %s", exc)
        return {
            "status": "error",
            "message": f"Gemini API error: {exc}",
            "bugs": [],
            "viewport": viewport,
            "image_path": image_path,
        }

    logger.debug("VLM raw response: %s", raw)

    try:
        # Strip potential markdown fences
        if raw.strip().startswith("```"):
            lines = raw.splitlines()
            if lines[0].startswith("```"):
                lines = lines[1:]
            if lines and lines[-1].startswith("```"):
                lines = lines[:-1]
            raw = "\n".join(lines)
            
        data = json.loads(raw)
    except json.JSONDecodeError as jde:
        logger.error("Failed to parse VLM JSON: %s", jde)
        return {
            "status": "error", 
            "message": "JSON parsing error", 
            "bugs": [], 
            "raw_response": raw,
            "viewport": viewport,
            "image_path": image_path
        }

    bugs = data.get("bugs", [])
    
    # Ensure viewport and screenshot_path are correct in every bug
    for bug in bugs:
        bug.setdefault("screenshot_path", image_path)
        bug.setdefault("viewport", viewport)
        bug.setdefault("confidence", 1.0)

    return {
        "status": "success",
        "bugs": bugs,
        "viewport": viewport,
        "image_path": image_path,
        "raw_response": raw
    }

from playwright.async_api import async_playwright

async def crop_element_region(
    image_path: str,
    page_url: str,
    css_selector: str,
    viewport_name: str = "desktop",
    padding: int = 20
) -> Optional[str]:
    """
    Crop a specific element's region from a full-page screenshot.
    """
    from backend.services.browser.automation import VIEWPORTS
    
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        try:
            dimensions = VIEWPORTS.get(viewport_name, VIEWPORTS["desktop"])
            context = await browser.new_context(viewport=dimensions, device_scale_factor=1)
            page = await context.new_page()
            await page.goto(page_url, wait_until="networkidle", timeout=30000)
            
            import asyncio
            await asyncio.sleep(1)
            
            locator = page.locator(css_selector).first
            box = await locator.bounding_box()
            if not box:
                logger.warning(f"Could not find bounding box for selector {css_selector}")
                return None
                
            x, y, w, h = box['x'], box['y'], box['width'], box['height']
            
            path = Path(image_path)
            if not path.is_file():
                return None
                
            with Image.open(path) as img:
                left = max(0, x - padding)
                top = max(0, y - padding)
                right = min(img.width, x + w + padding)
                bottom = min(img.height, y + h + padding)
                
                cropped = img.crop((left, top, right, bottom))
                
                out_path = path.parent / f"{path.stem}_cropped_{hash(css_selector)}{path.suffix}"
                cropped.save(out_path)
                return str(out_path.absolute())
                
        except Exception as e:
            logger.error(f"Failed to crop element region: {e}")
            return None
        finally:
            await browser.close()

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.

#!/usr/bin/env python3
"""
OmniSight — Quick Start Script
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Sets up the development environment and starts the backend server.
Usage: python scripts/start_dev.py
"""

import os
import subprocess
import sys
from pathlib import Path


def main() -> None:
    """Set up and start the OmniSight development server."""
    project_root = Path(__file__).resolve().parent.parent

    # Check for .env file
    env_file = project_root / ".env"
    env_example = project_root / ".env.example"

    if not env_file.exists():
        print("⚠️  No .env file found. Copying from .env.example...")
        if env_example.exists():
            import shutil
            shutil.copy(env_example, env_file)
            print("✅ Created .env — please update it with your API keys.")
        else:
            print("❌ .env.example not found either!")
            sys.exit(1)

    # Start uvicorn
    print("\n🚀 Starting OmniSight backend server...")
    subprocess.run(
        [
            sys.executable,
            "-m",
            "uvicorn",
            "backend.main:app",
            "--host", "0.0.0.0",
            "--port", "8000",
        ],
        cwd=str(project_root),
    )


if __name__ == "__main__":
    main()
